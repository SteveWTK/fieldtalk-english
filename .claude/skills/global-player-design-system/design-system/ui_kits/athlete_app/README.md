# Athlete app — UI kit

The player-facing daily surface, shown in a 390×780 frame (26px device radius, per `--gp-radius-device`).

**Click-through:** **Hoje** (today's lesson cards in their signal colours, readiness chip, one lime *Começar*) → tap a card → **Aula** (the drill lines in the mono register, module progress, *Concluir*) → **Prontidão** (the 81 score with segment pips and the mono "MEDIDO EM TEMPO REAL · NÃO É OPINIÃO" line).

This is the one surface written in second person, and even there it's imperative — "Fala com o treinador", "Começar", "Fazer depois". Tab targets are 44px minimum.
