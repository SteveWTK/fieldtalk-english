# Marketing site — UI kit

PT-first acquisition site for academias, clubes and agentes. Dark throughout, one lime CTA per section, the corner lime bloom only behind the hero.

Sections: `SiteHeader.jsx` (sticky, open mark, PT · EN) · `Hero.jsx` (fully bilingual copy) · `Modules.jsx` (the three trilhas in their signal colours, with the mono drill register) · `Tiers.jsx` (TierBadge-led pricing, Clube featured with a lime border) · `SiteFooter.jsx`.

The locale toggle in the header swaps the hero copy live — PT strings run ~20% longer, which is why nothing in the hero has a fixed height.
