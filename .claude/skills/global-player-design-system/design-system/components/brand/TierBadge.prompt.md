Encodes the B2B tier as 1/2/3 bars of the mark — pricing tables, plan rows, account badges.

```jsx
<TierBadge tier="academia" />   {/* Single squad, core lessons */}
<TierBadge tier="clube" />      {/* All youth divisions, skill radar */}
<TierBadge tier="federacao" />  {/* Multi-club, export dossiers */}
```

The topmost visible bar is always lime 400. Never use it as a logo substitute.
