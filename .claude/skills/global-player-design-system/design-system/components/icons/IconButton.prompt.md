Icon-only control — toolbars, table row actions, close buttons, mobile nav.

```jsx
<IconButton icon="search" label="Buscar atleta" />
<IconButton icon="download" label="Baixar dossiê" variant="outline" />
<IconButton icon="plus" label="Novo atleta" variant="solid" />
<IconButton icon="x" label="Fechar" size="sm" />
```

`label` is required. On mobile use `md` or `lg` so the target clears 44px.
