A Lucide glyph, locked to the brand's drawing (stroke 2, round caps, currentColor).

```jsx
<Icon name="search" />
<Icon name="download" size={24} label="Baixar dossiê" />
<Icon name="chevron-right" color="var(--gp-lime-400)" />
```

Icons are always `--gp-text-muted` at rest and `--gp-text-primary` on hover. Never recolour an icon lime unless it sits inside a lime-accented control, and never use the chevron mark as an icon — that is the logo.
