The only button. Uppercase Archivo 800 in a full pill; one lime `primary` per view.

```jsx
<Button>Novo atleta</Button>
<Button variant="secondary" size="lg">Ver a plataforma</Button>
<Button variant="ghost" size="sm">Cancelar</Button>
<Button disabled>Enviar dossiê</Button>
```

Hover lifts to lime 300, press to lime 500, focus is a 2px lime ring at 2px offset. Never scale on press. PT labels run ~20% longer than EN — don't fix widths.
