# Sales deck — sample slides

1280×720 at authoring size (the 16:9 frame scales to fit its card). Five types, one file each:

- `TitleSlide` — corner lime bloom, open mark top-left, Archivo 900 statement, a single meta line.
- `StatSlide` — three columns on 3px accent rules; exactly one rule is lime.
- `ModuleSlide` — the three trilhas in their signal colours with MetricBars.
- `QuoteSlide` — full-bleed lime with ink type; the one loud slide in the deck. Never two in a row.
- `ClosingSlide` — vertical crest lockup with the slogan, one lime CTA, the tier row.

Background budget for a whole deck: the corner bloom for open and close, flat slate for everything in between, and at most one lime slide. Body text never below 20px at this size.
